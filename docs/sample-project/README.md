GEAR Agent Framework는 교육 및 연구 목적으로 설계된 경량 Agentic AI 프레임워크입니다.

## 특징

- 모듈식 도구 시스템
- 계획-실행-검증 루프
- LLM 백엔드 추상화

## 빠른 시작

```bash
pip install gear-agent
```
